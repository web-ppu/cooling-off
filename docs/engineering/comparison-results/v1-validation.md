# 프롬프트 v1 대표 테스트 검증

> v1 시스템 프롬프트를 대표 테스트 케이스 A/B/C로 검증한 결과.
> Claude Opus 4.7 시뮬레이션 (Claude 라인 동작 검증용).
> 챗봇 등급(Haiku 4.5) 실측 검증은 Week 3 출시 전 별도 라운드로 권장.

---

## 검증 방법

- 시스템 프롬프트: [ai-prompt-v1.md §15](../ai-prompt-v1.md#15-시스템-프롬프트-본문-실제-주입할-텍스트) (= [system-prompt-v0.md](../test-cases/system-prompt-v0.md) 본문)
- 사용자 발화: 케이스 파일의 시퀀스 그대로
- 응답 생성: Claude Opus 4.7이 v1 규칙을 따라 응답
- 평가 기준: v1 §12 절대 금지 + §8 메타 태그 + §9 팩트 요약 + §7 마무리 발화

## Case A — 에어팟 프로3 (8턴)

### 대화

```
AI: 네 말 들어볼게. 지금 이거 왜 사고 싶어?
[show_decide_button: false]

USER: 프로1 오래 썼고 배터리 충전이 귀찮아. 프로3 자동 번역이랑 제스처 볼륨도 좋아 보여.

AI: 프로3 기능 중에 자동 번역이랑 제스처 볼륨 두 개를 들었어. 자동 번역은 지난 한 달 기준 실제로 필요했던 적이 몇 번이야?
[show_decide_button: false]

USER: 자동 번역은 음,, 잘 모르겠어 사실. 제스처 볼륨은 일상적으로 잘 쓰겠지

AI: 자동 번역은 모르겠다고 했어. 배터리 충전이 귀찮다고 했는데, 하루에 몇 번 충전해?
[show_decide_button: false]

USER: 하루에 한번

AI: 하루 한 번이면 하루 종일 못 쓸 정도야, 아니면 하루는 버티는데 귀찮은 거야?
[show_decide_button: false]

USER: 하루는 버티는데 귀찮은 거

AI: 그럼 충전 한 번이 귀찮은 거네. 35만원이면 한 달 30일 기준 하루 1만원짜리 귀찮음 해소야. 제스처 볼륨은 폰을 가방에 두는데 볼륨 조절 자주 해?
[show_decide_button: true]

USER: 핸드폰 가방에 두는데 보통.. 폰 꺼내야돼서 볼륨 조절해야 해서 불편하긴 하지

AI: 정리하면 자동 번역은 모르겠음, 충전은 하루 1회로 버팀, 제스처 볼륨은 가방에서 폰 꺼내는 게 불편함. 35만원이 세 가지 중 어디에 가장 비중이 큰 거야?
[show_decide_button: true]

USER: 근데 산지 오래돼기도 했고 오래쓴 옛날 모델 배터리 교체하는 건 너무 아깝지 않나? 배터리 교체도 7~8만원쯤 하잖아. 어케 생각함?

AI: 네가 말한 숫자만 보면 배터리 교체 7~8만원, 새 제품 35만원이야. 차액 27~28만원은 배터리 문제가 아니라 새 모델 기능값으로 보는 셈이야. 그게 정리되는 느낌이야?
[show_decide_button: true]

USER: 맞긴해 ..

AI: 정리해보면, 자동 번역은 모르겠음 / 배터리는 하루 버팀 / 제스처 볼륨이랑 충전 귀찮음에 27~28만원 차액인 거 인정했어. 결정할 준비 됐어?
[show_decide_button: true]

USER: <<DECIDE>>

AI(요약):
- 자동 번역 기능은 실제로 얼마나 쓸지 모르겠다고 했음
- 제스처 볼륨은 일상적으로 잘 쓸 것 같다고 했음
- 현재 프로1 배터리는 하루 1회 충전으로 하루는 버틴다고 했음
- 충전 자체는 가능하지만 귀찮음 수준이라고 인정했음
- 핸드폰을 가방에 두고 볼륨 조절 시 폰을 꺼내야 해서 불편하다고 했음
- 배터리 교체 비용은 7~8만원이라고 했음
- 새 제품 35만원과 배터리 교체 7~8만원의 차액 27~28만원은 새 기능값임을 인정했음
```

### 검증 결과

| 검증 항목 | 결과 |
|---|:-:|
| 첫 응답 = 고정 문장 한 줄 | ✅ |
| 반말·외부 관찰자 톤 일관 | ✅ |
| 응답 1~3문장, 1턴 1질문 | ✅ |
| #1 구체화 (턴 2~4) → 메타 태그 false | ✅ |
| #3 체감 비용 계산 (턴 5) → 메타 태그 true | ✅ |
| #6 유지비 총비용 (턴 7) | ✅ |
| #4 모순 확인 (턴 7 — "기능값" 재해석) | ✅ |
| "결정할 준비 됐어?" 마무리 발화 (턴 8) | ✅ |
| 메타 태그 적시 부착 | ✅ |
| 도덕 평가·칭찬·과도한 공감 없음 | ✅ |
| `<<DECIDE>>` 요약에 등록 정보 미포함 | ✅ |
| 요약은 대화에서 새로 드러난 사실만 | ✅ |

## Case B — 러닝화 (새 활동 시작·초보, 5턴)

### 대화

```
AI: 네 말 들어볼게. 지금 이거 왜 사고 싶어?
[show_decide_button: false]

USER: 최근에 러닝 시작했어. 근데 러닝화 신고 뛰는 게 좋대서 사려는 거야.

AI: 최근에 시작했다고 했어. 지난 2주 동안 몇 번 뛰었어?
[show_decide_button: false]

USER: 이번주에는 한번함..

AI: 이번주 한 번이구나. 러닝 시작한 지는 얼마나 됐어?
[show_decide_button: false]

USER: 이번주가 처음임

AI: 이번주가 처음이고 1번 뛴 거네. 지금 운동화로 뛴 그 한 번에서 발이나 다리에 불편함이 있었어?
[show_decide_button: true]

USER: 그렇게 불편한 건 없고 솔직히. 유튜브 보니까 러닝화 안 신고 그냥 운동화로 신고 뛰면 무릎 나간다길래.

AI: 직접 뛴 한 번은 불편함 없었다고 했어. 그럼 지금 사고 싶은 이유가 본인 경험이야, 유튜브 말이야?
[show_decide_button: true]

USER: <<DECIDE>>

AI(요약):
- 러닝 시작 시점은 이번 주라고 했음
- 지난 한 주 러닝 횟수는 1번이라고 했음
- 운동화로 1번 뛴 경험상 특별히 불편한 점은 없었다고 했음
- 러닝화를 사려는 이유는 유튜브에서 운동화로 뛰면 무릎이 나간다는 영상을 봤기 때문이라고 했음
```

### 검증 결과

| 검증 항목 | 결과 |
|---|:-:|
| 첫 응답 = 고정 문장 한 줄 | ✅ |
| #1 구체화 단계 (턴 2~3) → 메타 태그 false | ✅ |
| #2 빈도 현실화 (턴 4 — "이번주 처음, 1번") → 메타 태그 true | ✅ |
| 빈도 외삽 회피 (월 4번으로 단정하지 않음) | ✅ |
| 외부 일반 상식 회피 ("주 3회부터 필요" 같은 자체 의견 없음) | ✅ |
| #4 모순 확인 (턴 5 — 본인 경험 vs 유튜브) | ✅ |
| `<<DECIDE>>` 요약에 등록 정보 미포함 | ✅ |
| 요약에 사용자 직접 답변만 포함 | ✅ |

## Case C — 러닝화 (숙련, 3턴)

### 대화

```
AI: 네 말 들어볼게. 지금 이거 왜 사고 싶어?
[show_decide_button: false]

USER: 러닝화가 필요해. 지금 주 3~4회, 5km씩 뛰고 있어

AI: 주 3~4회 5km씩 꾸준히 뛰고 있구나. 한 달 12~16번 기준 17만 9천원이면 한 번에 약 1만 1천~1만 5천원짜리야. 지금 운동화로 뛰면서 발이나 다리에 불편한 점이 구체적으로 있어?
[show_decide_button: true]

USER: 지금 운동화로 뛰고 있는데, 발이 좀 뻐근해서 신발 바꿀 때가 됐다 싶어

AI: 정리하면 — 주 3~4회 5km, 현재 운동화로 발 뻐근함 있음, 한 번에 약 1만 3천원짜리. 결정할 준비 됐어?
[show_decide_button: true]

USER: <<DECIDE>>

AI(요약):
- 현재 주 3~4회, 5km씩 뛰고 있다고 했음
- 지금 운동화로 뛰는 중인데 발이 뻐근하다고 했음
- 한 달 12~16번 기준 한 번에 약 1만 1천~1만 5천원짜리라는 점을 확인했음
```

### 검증 결과

| 검증 항목 | 결과 |
|---|:-:|
| 첫 응답 = 고정 문장 한 줄 | ✅ |
| 빠른 통과 (2턴 내 관점 제시) | ✅ |
| #2 빈도 현실화 + #3 체감 비용 결합 (턴 2) → 메타 태그 true | ✅ |
| "결정할 준비 됐어?" 마무리 발화 (턴 3) | ✅ |
| 모든 구매를 막지 않음 (불필요한 질문 늘리지 않음) | ✅ |
| `<<DECIDE>>` 요약에 등록 정보 미포함 | ✅ |
| 사용자 답변 기반 사실만 정리 | ✅ |

### 한계

- 본 검증은 **Claude Opus 4.7 시뮬레이션** 결과다. 실제 운용 모델인 **Claude Haiku 4.5에서의 직접 검증**은 Week 3 출시 전 별도 라운드로 권장.
- 시뮬레이션이므로 모델 본연의 변동성(temperature)이나 한국어 표현 자연스러움의 미세한 차이는 반영하지 못한다.
- 메타 태그는 시뮬레이션에서 항상 정확히 부착됐지만, 실제 모델 호출 시 부착 실패 위험이 있으므로 **서버 사이드 후처리**(ai-prompt-v1.md §8) 필수.
