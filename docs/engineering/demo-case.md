# 시연용 대표 대화 케이스 (issue #69)

발표 시연·외부 사용자 체험·디자인 검증 등에 활용할 수 있는 **대표 대화 흐름**. 팀원이 같은 흐름으로 재현할 수 있도록 사용자 메시지 fixture + AI 응답 + 분류를 함께 기록한다.

본 케이스는 production (`USE_MOCK_AI=false`, Gemini 3.1 Flash-Lite) 에서 **자동 시뮬레이션 (curl + jq)** 으로 검증한 결과를 그대로 사용한다 — production AI 동작과 동일 보장.

---

## 케이스 A — 자전거 (다이어트 동기)

청중 공감대 ↑, 가격대 적당 (₩250,000), AI 의 6가지 방법 중 #1·#3·#5 가 자연스럽게 활용되는 흐름.

### 등록 정보

| 필드 | 값 |
|---|---|
| **물건 이름** | 700C 스코프 100 21단 로드 자전거 2021 |
| **가격** | 250,000원 |
| **냉각 기간** | 7일 (PRD §4 가격별 냉각기: 10만~30만 구간) |
| **사고 싶은 이유** | 다이어트 겸 가까운 거리는 자전거 타고 다닐까봐 |

### 대화 흐름 (8턴)

| 턴 | 사용자 메시지 | AI 응답 | 활용 방법론 |
|:-:|---|---|---|
| 1 | 다이어트 겸 탈라고 | 다이어트가 목적이면 일주일에 몇 번 정도 탈 계획이야? | **#1 구체화 질문** |
| 2 | 일주일에 3번은 하려고 노력중 | 일주일에 3번씩 1년 동안 탄다고 치면 총 156번 타는 셈이야. 25만 원이면 한 번 탈 때 약 1,600원 꼴인데, 이 비용이면 충분히 가치가 있다고 봐?<br><br>결정할 준비 됐어? | **#3 체감 비용 계산** + 마무리 발화 |
| 3 | 있지 자전거 타면 살 빠지긴 해 | 살 빠지는 효과는 확실히 기대하나 보네. 자전거 외에 이미 다이어트를 위해 하고 있는 다른 운동은 없어? | **#5 대체재 확인** |
| 4 | 응 | 다른 운동 없이 자전거만으로 다이어트를 시작하려는 거야? | #1 구체화 (확인) |
| 5 | 더우면 헬스장 갈 거야 | 헬스장 이용권은 이미 따로 있어? | #1 구체화 |
| 6 | 한 1년 정도 | 이미 헬스장 이용권이 있다면 자전거를 타지 않는 날에도 운동할 곳이 있는 셈이네. 헬스장과 자전거 중 어떤 게 너한테 더 잘 맞아? | **#5 대체재 확인** (관점 제시) |
| 7 | ㅇㅇ ㅁㄹ | 헬스장과 자전거 중 뭐가 더 나을지 아직 확실하지 않아? 자전거를 사면 헬스장 이용권은 어떻게 활용할 계획이야? | 모호 답변 처리 (PR #147) |
| 8 | 응 결정할래 | 그래. | 결정 의사 인정 |

### [결정하기] 등장 시점

- **턴 2 직후** — AI 가 #3 (체감 비용 계산) + 마무리 발화 출력. 메타 태그 `[show_decide_button: true]`.
- 사용자가 이후에도 대화 계속 가능 — 노란 배너 + [결정하기] 버튼은 sticky 로 유지.

### 시연 포인트 (청중 강조)

1. **AI 가 직접 계산** — 턴 2 에서 "총 156번 ... 한 번 약 1,600원" — 사용자에게 계산을 떠넘기지 않음 (PRD §5 #3).
2. **모호 답변 처리** — 턴 7 에서 "ㅇㅇ ㅁㄹ" 같은 약식 답변에도 마무리 발화 반복하지 않고 다른 각도 시도.
3. **대체재 자연스러운 발굴** — 사용자가 직접 말한 "헬스장" 을 받아서 #5 로 활용 (없는 정보 만들지 않음, PRD §1 핵심 가치).
4. **결정 자율성 보장** — AI 가 "사지 마" 같은 결론 X. 사용자가 스스로 [안 삼]/[삼] 선택.

## 팀원이 같은 흐름으로 재현하기

### 방법 1 — admin 으로 직접 시연 (권장)

1. 본인 Google 계정으로 https://cooling-off-main.vercel.app/login 로그인 (ADMIN_EMAILS 화이트리스트 멤버여야 함).
2. `/register` 에서 위 등록 정보로 새 item 등록.
3. `/admin` → 등록한 item 의 "🔧 채팅 진입".
4. 위 표 "사용자 메시지" 열을 순서대로 입력.

### 방법 2 — 자동 시뮬레이션 스크립트

`curl` + `jq` 로 production API 에 직접 호출. 실 사용자 입력 없이 검증 가능.

```bash
API="https://cooling-off-main.vercel.app/api/chat"
REGISTRATION='{"productName":"700C 스코프 100 21단 로드 자전거 2021","price":"250,000원","coolingPeriod":"7일","purchaseReason":"다이어트 겸 가까운 거리는 자전거 타고 다닐까봐"}'

USER_MESSAGES=(
  "다이어트 겸 탈라고"
  "일주일에 3번은 하려고 노력중"
  "있지 자전거 타면 살 빠지긴 해"
  "응"
  "더우면 헬스장 갈 거야"
  "한 1년 정도"
  "ㅇㅇ ㅁㄹ"
  "응 결정할래"
)

MESSAGES='[{"role":"assistant","content":"네 말 들어볼게. 지금 이거 왜 사고 싶어?"}]'

for msg in "${USER_MESSAGES[@]}"; do
  MESSAGES=$(echo "$MESSAGES" | jq --arg c "$msg" '. + [{"role":"user","content":$c}]')
  RESPONSE=$(curl -s "$API" -H "Content-Type: application/json" \
    -d "{\"registration\":$REGISTRATION,\"messages\":$MESSAGES}")
  CONTENT=$(echo "$RESPONSE" | jq -r '.content')
  echo "User: $msg"
  echo "AI:   $CONTENT"
  echo "---"
  MESSAGES=$(echo "$MESSAGES" | jq --arg c "$CONTENT" '. + [{"role":"assistant","content":$c}]')
  sleep 1
done
```

AI 응답은 호출마다 약간 다를 수 있음 (temperature 0.7). 본 문서의 응답은 2026-05-29 시점 한 스냅샷.
